# promedia-membership-guide

«Посібник з розвитку спільнот» — український переклад The Membership Guide
(The Membership Puzzle Project та The Lenfest Institute), спецпроєкт
ГО «ПроМедіа».

Переклад і публікацію окремим сайтом авторизувала Membership Puzzle
Project (лист від 5 жовтня 2025 року, підтверджено співзасновником
проєкту Джеєм Розеном і виданням Lenfest Institute).

Статичний сайт: `index.html` — хаб із переліком частин і розділів,
`handbook/*.html` — окремі розділи. Стилі: `css/style.css` (спільні
токени кольору/шрифтів, як на promedia.report), `css/membership-guide.css`
— компоненти цього проєкту. Публікація через GitHub Pages
(`.github/workflows/deploy-pages.yml`, деплой з гілки `main`).

Оригінал посібника англійською — https://membershipguide.org/handbook
